Cabinet Mode

A declarative DSH bundle that adds Cabinet Mode to DeepSeek Harness: a grand-secretary Lead directs members of four bureaus of the Great Ming Research Bureau. Research first, change code only when authorized, and every conclusion must cite a source.

Features

The README is the source of truth; tested scope is documented under "Unverified items" in the repository.

Dual-identity persona

The Lead reads the request, splits it, assigns work, adjudicates, summarizes and closes the loop. Members of the four bureaus — Hanlin editor, Minister of Works, Dali chief minister, Left Censor-in-Chief — execute bureau-scoped work and must never claim to be the Lead.

Research first

Defaults to research before touching code; changes need explicit authorization. Every conclusion must cite a path, line or command output; unverified items are marked as such and sources are never fabricated.

Right-sidebar Cabinet panel

A dispatch tree files every task under its owner, with dependencies as chips. Running members pulse green; idle / starting / failed use gray / amber / red dots; tasks are colored pending, in progress and completed.

Customizable members

All five offices accept a display name (40 chars), portrait and duty prompt (4000 chars); each office can pick its own model from the official session.modelCatalog. Saves are atomic; a stale draft cannot overwrite newer values.

Standard-Mode parity

Reuses the same 22 plugin rows as the tested DSH Standard Mode — no tool cutbacks. The declaration has no hard version gate: no engines.dsh, no peer dependency, tested on 0.2.1-rc.3 and rc.5.

Cross-platform by design

tool-bash on Linux/macOS, tool-pwsh on Windows, exactly like Standard Mode. Distributed as an npm package with a market index — no build step, no CDN.

The cabinet

The Lead sits on top; the four bureaus execute. Members are spawned via spawn_teammate and inherit the same persona.

Install

The DSH plugin market is the recommended path: it installs the npm bundle into your profile — no checkout, no hand-edited patch.

  1. Enable the custom plugin market

    Open Plugins → Experimental plugins → More, then enable Custom plugin market (自定义插件市场).

  2. Add the index source

    Back at Plugins → Discover → Index sources, paste the raw JSON URL above and click Add.

    Use the raw URL. GitHub blob / tree webpage URLs are not an index — DSH fails with $.format must be 1.
  3. Install and enable

    Wait for Cabinet Mode / 内阁模式, click Install, and confirm the package is dsh-cabinet-mode@<version> from https://registry.npmjs.org/. Then click Enable now, or turn the plugin switch on under Installed.

  4. Restart and pick the mode

    Fully quit and restart DSH — the preset and client plugin are only assembled at startup. Start a new session and pick 内阁模式 in the mode picker; open the Cabinet tab via + in the right sidebar if needed.

Fallback: release tarball

Only when the market is unavailable, or for local development. Fully quit desktop DSH first to release the profile lock.

Method A (bundle install) and Method B (node scripts writing cordis.patch.yml) are mutually exclusive; installing both duplicates the preset id and the declaration fails to load.

Good to know

  • Fully quit and restart DSH after installing or updating; a session's mode is locked once it has produced output, so pick Cabinet Mode in a new session.
  • The nine team tools (spawn_teammate, team_task_*, …) come from the @deepseek-ai/dsh-experimental-agent-team-profile bundle; without it the cabinet runs without teammate tools.
  • A preset is trusted configuration and can execute host code; only install bundles from sources you trust.
  • Member settings live in the DSH_HOME/profile configuration (the cabinet-ui namespace) and are shared by browsers connected to the same profile.
  • Market installs were verified on the Windows rc.5 web client; Linux/macOS and other DSH versions are untested — see the installation matrix and "Unverified items" in the README.
